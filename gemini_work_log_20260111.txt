PROBLEMA:
El script `extractores/2.DIARIO.daily_urls_extraction.VCLI.py` fallaba y no encontraba autos.
Causa: NeoAuto cambió su estructura front-end, eliminando clases CSS antiguas (`c-results__link`) e implementando Next.js con hidratación client-side. Los datos ahora vienen en un string JSON dentro del HTML, no en etiquetas `<a>` simples.

SOLUCIÓN:
Se implementó una estrategia de extracción multi-capa (Multi-Strategy Extraction) para máxima robustez:

1. Estrategia Principal (Regex JSON Escapado):
   - Se busca el patrón `\"slug\":\"/auto/...\"` que corresponde a cómo Next.js serializa los datos en el HTML.
   - Esto bypass al problema de renderizado JS.

2. Estrategia Secundaria (Regex JSON Simple):
   - Fallback para JSON no escapado estándar.

3. Estrategia Terciaria (Regex HTML):
   - Búsqueda directa de `href="..."` en caso de que NeoAuto revierta a HTML estático.
